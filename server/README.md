# MERN Job Portal

##  Project Status
 This project is currently under development.

##  About
A full-stack Job Portal web application built using the MERN stack (MongoDB, Express.js, React.js, and Node.js). It allows students/job seekers to search and apply for jobs, while recruiters can post and manage job listings.

##  Features Completed
- User Registration
- User Login
- JWT Authentication
- Password Hashing using bcrypt
- MongoDB Database Integration
- REST API Setup

##  Features in Progress
- Resume Upload
- Job Posting
- Job Application
- Recruiter Dashboard
- Student Dashboard

##  Tech Stack
- React.js
- Node.js
- Express.js
- MongoDB
- JWT
- bcrypt
- Multer

##  How to Run

### Backend
```bash
cd server
npm install
npm run dev
```

### Frontend
```bash
cd client
npm install
npm run dev
```
